VELMORA — a vintage travel poster for a place that isn't there. A fictional archipelago of floating islands in the sky, with one white-and-gold lighthouse as its landmark, lit by golden-hour sun over a calm glowing sea. The place name VELMORA is set in large type at the top, with the subtitle "ISLANDS IN THE SKY". No quotes, no star ratings.

## Run it

```sh
python3 main.py
```

Writes the poster to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`), a 1024×1024 PNG under 1 MiB. Pure Python standard library, no network.
